# Discover 7 Power website — Version 1

A responsive, static website starter for Discover 7 Power. It runs locally without a server and is suitable for free static hosting.

## Preview on your HP / Windows laptop
1. Extract the website ZIP.
2. Open the extracted folder.
3. Double-click index.html (Chrome or Edge recommended).
4. Internet connection is needed for optional Google Fonts. The site itself works without them.

## Add your videos
Copy MP4 files into assets/videos/ and use these exact filenames:
- company-introduction.mp4 — company introduction film
- the-devils-agenda.mp4 — The Devil's Agenda documentary / final cut
- innovation-showreel.mp4 — Discover AI Power / innovation showcase

For a public website, copy the files into assets/videos. The browser-only Add video files preview does not upload files to the website.

## Free hosting
Upload the extracted website folder contents to a public GitHub repository. For GitHub Pages: repository Settings → Pages → deploy from branch → select main and /(root) → Save. No build command is required; publish directory is /.

Do not upload confidential material. A public repository makes website source files public.
